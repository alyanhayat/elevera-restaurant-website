# ÉLÉVÉRA — Luxury Fine Dining Restaurant Website

A modern and responsive fine-dining restaurant website built from scratch using HTML, CSS, and JavaScript.

## 🌐 Live Website

https://alyanhayat.github.io/elevera-restaurant-website/

## ✨ Features

- Responsive design
- Luxury restaurant UI
- Home page
- Menu page
- About / Our Story page
- Gallery page
- Reservation page
- Responsive navigation
- Hero sections
- Call-to-action sections
- Hover animations
- CSS animations and transitions
- Scroll-to-top button
- Mobile and tablet layouts
- Consistent restaurant branding

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- CSS Animations & Transitions

## 📱 Responsive

The website is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile
